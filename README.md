## **For converting historic images to .mind:**
https://hiukim.github.io/mind-ar-js-doc/tools/compile/

The size (Mbs) of the input images doesn't matter, neither does the format of the input image. The output .mind file will always stay the same size, since the output marker/tracker data stays the same.

## **For converting modern images from .png/.jpg to .webp:**
https://www.faststonesoft.net/DN/FSResizerSetup45.exe

From my experience, this is the fastest image converter that is also free.
