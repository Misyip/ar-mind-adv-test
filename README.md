## **Instructions for updating modern-day images:**
1. Log into the GitHub account with the provided credentials, by going to github.com and clicking the "Sign in" button in the top-right corner.
2. Open the "klaipeda-ar-postcards" GitHub repository.
3. In the main repository screen, go into the folder called "modern".
4. Find the modern-day image you want to update, by clicking through the images.
5. Once you've found your desired image, MAKE SURE TO REMEMBER THE NUMBER OF THE IMAGE, The one that is in the name of the image!
6. Delete the image: click on the "More file actions" three-dots icon, then press "Delete file" in the drop-down menu that appears.
7. After doing that you will be sent to an "Editing page", where you have to click the "Commit changes..." button, and then press the "commit changes" button that appears in the pop-up. After that, the image is deleted.
8. After deleting the image, you will be sent back to the main repository screen, go back into the "modern" folder.
9. When in the "modern" folder, click the "Add file" button, then click "Upload files" in the drop-down menu that appears.
10. You will now be sent to a "File upload" page.
11. BEFORE UPLOADING MAKE SURE TO CONVERT YOUR IMAGE TO .webp FORMAT AND RENAME THE IMAGE TO THE NUMBER FROM THE PREVIOUSLY DELETED FILE.
12. If you have converted the image and renamed it, then either drag and drop or click the "choose your files" button to upload your image.
13. Wait for the image to load into the upload page (there will be an upload progression bar for the specific file), when it has finished uploading to the page the progression bar will disappear from the specific file.
14. If it has finished uploading to the page, then click on the "Commit changes" button.
15. After clicking the "Commit changes" button you will be sent to a loading page, then sent back to the main repository screen.
16. Lastly, wait approximately 3 to 5 minutes for the AR Postcards app to parse the new image and update the AR Postcard website (this can be seen as an orange circle icon that turns into a green checkmark in the main repository screen).
17. Scan the historic AR Postcard and see that it has changed.

## **For converting historic images to .mind:**
https://hiukim.github.io/mind-ar-js-doc/tools/compile/

The size (MBs, not image resolution) of the input images doesn't matter, neither does the format of the input image. The output .mind file will always stay the same size, since the output marker/tracker data stays the same.

## **For converting modern images from .png/.jpg to .webp:**
https://www.faststonesoft.net/DN/FSResizerSetup45.exe

From my experience, this is the fastest image converter that is also free (needs to be installed on your PC).
